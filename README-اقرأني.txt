نسخة الاختبار المصححة — منيو نادي النسور
========================================

هذه الحزمة مخصصة لنسخة الاختبار فقط.
Worker: nady-el-nosour-menu-test
D1: nady_nosour_test_db
Binding: DB

مهم:
- لا ترفع هذه الملفات إلى Worker الإنتاج dawn-term-2eb2.
- لا تعدّل أو تحذف قاعدة الإنتاج nady-el-nosour-menu.
- لا تحتوي هذه الحزمة على بيانات أصناف أو أسعار، حتى لا يحدث أي تعديل أو استيراد غير مقصود.
- لم يتم تنفيذ أي استيراد أو نشر تلقائي من هذه الحزمة.

محتويات جذر المشروع:
- worker.js: واجهات قراءة المنيو وتسجيل دخول الإدارة والإضافة والتعديل والحذف.
- wrangler.jsonc: إعداد Worker الاختبار وربطه بقاعدة الاختبار الحالية.
- schema.sql: تعريف الجدول والفهرس.
- public/index.html: المنيو العام.
- public/admin.html: لوحة الإدارة.

بعد ربط الملفات بـ GitHub، يجب ضبط Secret باسم ADMIN_PASSWORD على Worker الاختبار فقط.
ثم نتحقق من /api/menu و /admin.html قبل استيراد أي بيانات أو إجراء أي تعديل.
